# Changelog

All notable changes to this project are documented in this file.

Changes are organized into the following categories:

- **Added:** New features or functionality introduced to the project.
- **Changed:** Modifications to existing functionality that do not add new features.
- **Fixed:** Bug fixes that resolve issues or correct unintended behavior.
- **Removed:** Features or components that have been removed from the project.

## [Unreleased]

- Changes for the next release are available in development branches.

## [v0.1.0] - 2026-02-21

### Added

- Add `README.md` with project overview and documentation
- Add community standards files (`CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `LICENSE`, `BRANCH_NAMING_GUIDELINES.md`, `COMMIT_MESSAGE_GUIDELINES.md`, `PULL_REQUEST_GUIDELINES.md`, `VERSIONING.md`, `TODO.md`, `CHANGELOG.md`)
- Add `commit.prompt.md` and `copilot-instructions.md` under `.github/`
- Add TypeScript and ESM support with `tsconfig.json`
- Add profile exports and basic CLI commands (`src/main.ts`, `bin/index.ts`)
- Add Vitest and example tests (`tests/main.test.ts`, `vitest.config.ts`)
- Add GitHub Actions publish workflow (`.github/workflows/publish.yml`)
